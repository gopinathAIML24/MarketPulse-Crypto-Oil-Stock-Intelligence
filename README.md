The Cryptocurrency & Financial Market Analytics Dashboard is an interactive data analytics application developed using Python, Pandas, SQL, APIs, and Streamlit.
The project collects cryptocurrency and financial market data from external sources, processes and stores the data, and presents meaningful insights through an interactive dashboard.
The main goal of this project is to make cryptocurrency and financial market information easier to understand through data visualization, filtering, comparison, and SQL-based analysis.

    
**Objectives**
Collect real-time cryptocurrency market data using an API.
Perform data cleaning and preprocessing using Python.
Store and manage data using SQLite.
Analyze cryptocurrency and financial market data using SQL.
Create interactive visualizations and dashboards.
Allow users to filter and explore the available data.
Provide meaningful insights from the collected data.
